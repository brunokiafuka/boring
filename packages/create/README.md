# @boring-dev/create

Scaffold a [BoringJS](https://github.com/brunokiafuka/boring) application.

```bash
pnpm create @boring-dev my-app
npm create @boring-dev@latest my-app
```

You get a working app with one feature, a test, and the `check` and `explain` commands wired up. No database
and no auth until you add them; the README in the new app shows how.

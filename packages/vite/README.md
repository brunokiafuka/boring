# @boring-dev/vite

The Vite plugin: serves the app, provides the `@/` alias, keeps server code out of the browser, brings the React adapter.

```bash
pnpm add -D @boring-dev/vite
```

Part of [BoringJS](https://github.com/brunokiafuka/boring). Start a new app with `pnpm create @boring-dev my-app`; the framework README covers the whole model.

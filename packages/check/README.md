# @boring-dev/check

`boring check` enforces the shape rules; `boring explain [file]` prints features, URLs and layouts.

```bash
pnpm add -D @boring-dev/check
```

Part of [BoringJS](https://github.com/brunokiafuka/boring). Start a new app with `pnpm create @boring-dev my-app`; the framework README covers the whole model.

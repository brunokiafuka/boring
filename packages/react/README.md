# @boring-dev/react

The rendering adapter: server render, hydration, client router, `Outlet`, and the form-aware JSX runtime.

```bash
pnpm add @boring-dev/react react react-dom
```

Part of [BoringJS](https://github.com/brunokiafuka/boring). Start a new app with `pnpm create @boring-dev my-app`; the framework README covers the whole model.
